# 校园猫鼠大作战 2.0 阶段报告

## 代码改了什么

- 保留旧引擎和 24 项原有规则测试，在兼容层外增加 30 Hz 固定步长模拟器。
- 玩家支持方向键、WASD 和触屏方向按钮持续移动；整段路径使用扫掠碰撞防止高速穿楼。
- NPC 使用本地 OSM 可步行道路与人工核验演示通行线组成的 42 节点路网，通过 A* 追逐或逃跑。
- 玩家抓捕改为“进入范围 → 模拟触碰确认 → 阵营转换”；增加事件反馈和声音开关。
- 结算使用两小时有效的 `sessionStorage` 摘要，跨路由可恢复，但不保存精细位置轨迹。
- 新增统一测试、生产浏览器验收、移动端/离线/结算截图和演示说明。

## 运行效果是什么

- MapLibre 本地校园场景继续作为页面主体，建筑、道路、绿化、水域、活动边界和角色无需在线瓦片即可显示。
- 地图支持缩放、旋转、倾斜、镜头跟随和全场视野；玩家与 NPC 都连续移动。
- 自动验收显示 6 个角色、OSM 署名和地图控件正常；断网后场景不消失；移动端无横向溢出。
- 47/47 项测试通过，Vite 生产构建通过，浏览器运行错误为 0。

## 还有什么问题

- 碰撞仍是建筑/水域外包矩形，不是真实多边形轮廓。
- 演示通行线未做现场核验，不能作为真实校园导航依据。
- MapLibre 使游戏页 chunk 约 1.08 MB，首次载入仍有优化空间。
- 当前没有 PWA 首次离线安装、真实 GPS、后端或多人联机。

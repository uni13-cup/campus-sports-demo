# 校园猫鼠大作战 2.0 架构

## 目标与边界

2.0 在现有 Vue 3 + Vite 单机演示上增量升级。游戏使用模拟二维米制坐标，地图渲染时再转换为 WGS84 经纬度；不接入真实 GPS、后端或多人联机。平台其他模块不在本次改动范围内。

## 单一数据流

```text
键盘 / 触屏输入
       ↓
固定步长模拟器（30 Hz）
       ↓
唯一 GameState → 计时 / 移动 / NPC / 抓捕 / 事件
       ↓
Vue 响应式状态
       ↓
MapLibre 标记与 HUD
```

- 页面以 `players` 为唯一角色数据源，不再并行维护猫、鼠或地图标记坐标。
- `GameState` 中的位置始终是模拟米制坐标；`CampusMap.vue` 只在渲染边界调用 `gameToLngLat()`。
- 新接口采用“传入状态、返回新状态”的方式，避免 UI、计时器和 AI 分别持有状态。
- `engine.js` 的模块级旧接口继续保留，作为兼容层；2.0 页面不再依赖它们。

## 模块职责

| 模块 | 职责 |
|---|---|
| `engine.js` | 规则、计时、兼容接口、基础距离与可行走判断 |
| `simulation.js` | 固定步长、连续输入、速度模型、扫掠碰撞 |
| `navigation.js` | 道路节点图、A*、NPC 路径与决策 |
| `capture.js` | 抓捕候选、模拟触碰确认、阵营转换、事件 |
| `result-store.js` | 会话级结算快照，不持久化精细轨迹 |
| `coordinates.js` | 模拟坐标与经纬度双向转换 |
| `CampusMap.vue` | 本地 MapLibre 场景、角色渲染、镜头控制 |

## 时间与运动

- 逻辑步长固定为 `1 / 30` 秒，渲染使用 `requestAnimationFrame`。
- 单帧真实时间会限幅；页面从后台恢复时清空累计时间，避免角色瞬移和倒计时突跳。
- 速度单位为模拟米/秒；对角输入归一化，避免斜向加速。
- 碰撞检查覆盖整段运动路径，而不只检查终点。

## 地图与碰撞声明

本地校园场景来自 OpenStreetMap 数据并保留署名。当前不可进入区仍使用建筑和水域的外包矩形近似；它与真实建筑多边形并不完全一致。2.0 的扫掠碰撞只解决高速穿越这些既有矩形的问题，不宣称已实现真实建筑轮廓碰撞。

## 回退策略

每个阶段使用独立提交。旧导出、旧测试和路由保持可用；若新模拟器出现问题，可回退对应阶段提交，不影响已经完成的本地 MapLibre 场景。

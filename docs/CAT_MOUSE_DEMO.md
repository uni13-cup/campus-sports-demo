# 校园猫鼠大作战 2.0 演示说明

## 本地运行

```powershell
npm install
npm run dev
```

打开终端显示的地址，进入“校园猫鼠大作战”。所有角色位置都标注为模拟定位数据，不代表真实 GPS。

## 60–90 秒演示流程

1. 在大厅说明规则：1 只玩家猫、5 只电脑鼠、5 秒躲藏、30 秒追捕。
2. 进入地图，展示本地校园建筑、道路、绿化、水域、活动边界与 OSM 署名。
3. 使用地图控件缩放、旋转和倾斜，再点击“查看全场”和“跟随玩家”。
4. 追捕开始后按住方向键或 WASD 连续移动；移动端按住方向按钮。
5. 观察电脑鼠沿演示路网逃跑；被抓后的电脑鼠会转为电脑猫并协助追逐。
6. 靠近电脑鼠后点击“模拟触碰确认”，展示抓捕反馈、阵营转换和计数变化。
7. 等待全部抓获或倒计时结束，展示结算页，再点击“再来一局”。

## 自动验收

先启动生产预览，再在另一个终端运行：

```powershell
npm run test:game
npm run build
npm run preview -- --host 127.0.0.1
npm run verify:game
```

浏览器脚本会输出 `artifacts/campus-map/verification.json`，并生成桌面地图、碰撞范围、连续移动、移动端和结算页截图。

## 数据与许可

- 校园场景来自 OpenStreetMap，本地打包为 GeoJSON，页面保留 `© OpenStreetMap contributors · ODbL 1.0` 署名。
- 运行时不请求在线瓦片；网络断开后，已加载的应用仍可显示校园场景和角色。
- 路网是活动区内 OSM 可步行道路与人工核验演示通行线的混合数据，不是官方或实时导航数据。
- 建筑碰撞仍使用建筑/水域外包矩形近似，不代表真实建筑轮廓。
